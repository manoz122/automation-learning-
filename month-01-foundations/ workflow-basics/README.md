
# Workflow Basics

## What is a workflow?

A workflow is a sequence of steps used to complete a task.

Basic structure:

Trigger → Input → Logic → Action → Output

## Example: Leave Request

Trigger:
Employee submits a leave request.

Input:
- Employee name
- Leave date
- Number of days
- Reason

Logic:
If leave days are more than 3 days, manager approval is required.

Action:
Send the request to the manager.

Output:
Approved or Rejected.
